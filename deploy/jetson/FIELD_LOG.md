# 실데모 현장 기록지 — 바다 테스트

> 이 종이 한 장이 데모를 **"잘 되더라"에서 측정치로** 바꾼다.
> 시스템이 자동으로 남기는 것(FPS·온도·경보 시각)과 **사람만 남길 수 있는 것**(실제로 뭐가 있었나,
> 조건이 어땠나)이 따로다. 아래는 후자다 — 나중에 절대 복원할 수 없으니 현장에서 적는다.
>
> 🔴 **정확도(recall·오경보율)는 이 기록만으로는 안 나온다.** 영상을 받아와 라벨링해야 나온다.
> 여기서 얻는 건 **이벤트 단위** 지표(표적 몇 척 중 몇 척 포착, 오경보 몇 회)다.

## 3. 표적 관측 로그

화면에서 **키를 눌러 기록**하면 프레임 번호·시각·그때의 탐지 결과가 자동으로 붙는다
(`runs/deploy_live/observations.jsonl` + 스냅샷). 아래 표는 그 옆에 **맥락**을 적는 칸이다.

| # | 시각 | 누른 키 | 실제로 본 것 (선종·척수·대략 거리) | 시스템 반응 | 비고 |
|---|---|---|---|---|---|
| 1 | | w / s / f / x | | 경보 ☐ 탐지만 ☐ 무반응 ☐ | |
| 2 | | | | | |
| 3 | | | | | |
| 4 | | | | | |
| 5 | | | | | |
| 6 | | | | | |
| 7 | | | | | |
| 8 | | | | | |

**키 의미** — `w` 군함 있음 / `s` 선박 있으나 군함 아님 / `f` 지금 경보는 오경보 / `x` 지금 놓치고 있다
